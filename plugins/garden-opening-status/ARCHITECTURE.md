# 開催情報管理プラグイン内部構成

## 目的

このプラグインは現在の公開機能を維持したまま、今後の改修時に変更範囲を判断しやすくするため、責務を以下の単位で扱います。

## 現在の責務

1. **会期・公開状態**
   - 春・秋・冬の会期情報
   - 即時／手動／指定日時公開
   - 開苑中・閉苑中などの状態判定
   - 指定日時公開時のキャッシュ更新

2. **トップページ開催状況**
   - 開催状況パネルの表示
   - PC／スマホ別レイアウト
   - 管理画面プレビュー
   - レイアウトテンプレート

3. **会期ページ表示**
   - 開苑期間・時間・料金の反映
   - 確定会期の公開判定
   - PC／スマホ実画面プレビュー
   - スマホ表示補正

4. **SEO・構造化データ**
   - 日本語主要ページ
   - 英語・繁体字ページ
   - 会期ページの確定日連動
   - OG / Twitter / schema / hreflang

5. **常設案内・サイト固有補正**
   - 常設案内カード
   - 終了済み会期案内
   - アクセスページ表示補正

6. **Instagram**
   - API設定
   - 定期取得
   - トップページ／ショートコード表示
   - 画像拡大表示

7. **管理・保存基盤**
   - `garden_opening_status_options`
   - バージョン移行
   - キャッシュ破棄
   - AJAXプレビュー保存

## 変更境界

機能改修では、まず上記のどの責務に属するかを決め、別責務へ変更を広げないことを基本とします。

特に以下は独立して扱います。

- 会期公開判定とSEO公開判定
- 保存処理と表示処理
- 管理画面プレビューと公開画面
- Instagramと会期管理
- 将来追加するトップスライダー管理と既存の開催状況表示

## 現時点で維持する外部契約

- WordPress option名
- 既存ショートコード名
- 既存管理画面URL
- 既存公開フック
- テーマファイルを直接変更しない方針

## 次回の内部コード分割方針

単一PHPの分割は、表示仕様変更や他プラグイン統合と同時には行いません。分割する場合は、上記責務単位でコード移動のみを行い、入出力・フック・optionを変更しない独立作業として扱います。
